# Milestone v1.0: Genome Skills

**Status:** SHIPPED 2026-04-02
**Phases:** 1-2
**Total Plans:** 4

## Overview

Two skills that create genome markdown specs — one from user descriptions (authoring), one from existing UiPath solutions (extraction). Authoring goes first because it establishes the genome format handling pattern that extraction also needs. Each phase delivers one complete, self-contained skill.

## Phases

### Phase 1: Genome Authoring Skill

**Goal**: Users can describe an automation idea and get a complete, well-structured genome markdown file back
**Depends on**: Nothing (first phase)
**Requirements**: AUTH-01, AUTH-02, AUTH-03, AUTH-04, AUTH-05
**Plans**: 2 plans

Plans:
- [x] 01-01-PLAN.md — Reference files (genome template with Build With section, skill-mapping guide) and CODEOWNERS
- [x] 01-02-PLAN.md — SKILL.md with interview workflow, critical rules, complexity inference, anti-patterns

### Phase 2: Genome Extraction Skill

**Goal**: Users can point the agent at an existing UiPath Studio solution and get a genome spec that captures what the solution does
**Depends on**: Phase 1
**Requirements**: EXTR-01, EXTR-02, EXTR-03, EXTR-04, EXTR-05
**Plans**: 2 plans

Plans:
- [x] 02-01-PLAN.md — Reference files (project-analysis-guide, extraction-mapping-guide) and CODEOWNERS
- [x] 02-02-PLAN.md — SKILL.md with extraction workflow, critical rules, population matrix, anti-patterns

## Milestone Summary

**Key Decisions:**
- Authoring before extraction: authoring establishes genome format handling; extraction benefits from that foundation
- Build With section placed between Acceptance Criteria and Complexity for readability flow
- Skill mapping uses 7-rule decision tree for ambiguous cases
- Complexity inference from project signals (file count, dependencies, entry points) for extraction
- Generalize business-specific values into Configuration Questions with original values as defaults
- Shared genome assets in `skills/shared/genome/` to avoid cross-skill references

**Issues Resolved:**
- Cross-skill dependency on skill-mapping-guide.md — moved to skills/shared/genome/

**Technical Debt Incurred:**
- None identified
