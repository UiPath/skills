# Requirements: UiPath Agent Skills — Genome Skills

**Defined:** 2026-04-02
**Core Value:** AI agents can autonomously build production-quality UiPath automations

## v1.0 Requirements

Requirements for genome creation skills. Each maps to roadmap phases.

### Genome Authoring

- [x] **AUTH-01**: User can describe an automation idea and receive a complete genome markdown file
- [x] **AUTH-02**: Agent asks configuration questions adapted to genome complexity (minimal for simple, full interview for complex)
- [x] **AUTH-03**: Genome output follows TEMPLATE.md format with all applicable sections populated
- [x] **AUTH-04**: Agent generates testable acceptance criteria derived from the described workflow
- [x] **AUTH-05**: Agent handles all three complexity levels (simple paragraph, medium single-file, complex multi-section)

### Genome Extraction

- [x] **EXTR-01**: Agent reads UiPath project structure (project.json, .xaml, .cs, .flow files) to understand the solution
- [x] **EXTR-02**: Agent identifies target applications, workflow steps, and business rules from project files
- [x] **EXTR-03**: Agent produces genome markdown following TEMPLATE.md format from analyzed solution
- [x] **EXTR-04**: Agent detects platform features in use (Document Understanding, Integration Service, Orchestrator queues, etc.)
- [x] **EXTR-05**: Agent extracts error handling patterns and maps them to genome error handling section

## Future Requirements

### Genome Management

- **MGMT-01**: CLI command to list/search genomes in a registry
- **MGMT-02**: CLI command to initialize a project from a genome
- **MGMT-03**: Genome versioning and update tracking

### Genome Distribution

- **DIST-01**: GitHub org hosting with topic tags for discovery
- **DIST-02**: Dedicated portal with search, tags, and ratings

## Out of Scope

| Feature | Reason |
|---------|--------|
| Genome execution skill | Genomes are self-contained; existing skills handle the build |
| Genome marketplace/ratings | Premature without 20+ genomes; defer to future |
| CLI-integrated registry | Infrastructure beyond the skills repo; Phase 2+ |
| Multi-file complex genomes | Template supports it but no examples exist yet; single-file first |
