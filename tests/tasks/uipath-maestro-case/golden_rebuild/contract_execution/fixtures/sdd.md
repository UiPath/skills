## Decisions Made

| # | Decision | Picked | One-sentence reason |
|---|---|---|---|
| 1 | Scope | Case Management | The work is a long-running legal lifecycle with human decisions, deadlines, rework, and terminal outcomes. |
| 2 | Stage model | Five primary stages and three secondary stages | Review and execution form the required journey; rejection, withdrawal, and overall-SLA intervention can interrupt or terminate it. |
| 3 | Task classification | Human actions, API workflows, agents, connector waits, and a child case | Human legal judgment remains with named roles while deterministic system work and optional analysis are automated. |
| 4 | Resource resolution posture | Portable intent with unresolved identities | This design-only run defers tenant resource wiring to the later build. |

### Case-Level SLA Escalation Rules

**Design Rationale:** The stated 10-business-day target warns the legal team at 70%; breach opens an interrupting intervention so Legal Operations and General Counsel act before closure.

| At-Risk | 70% of SLA duration | Notify: UserGroup: Legal Team | Contract Execution SLA at risk |
| Breached | 100% of SLA duration | Notify: UserGroup: Legal Operations | Contract Execution SLA breached |

## Non-Functional Requirements

| Dimension | Requirement / Design decision |
|---|---|
| Security | Use least-privilege role access; restrict contract documents, deal values, legal opinions, and personal data to authorized personas; keep credentials in managed connections. |
| Performance | Case actions and status updates should appear promptly; use event callbacks rather than polling for withdrawal and signature results. |
| Scalability | Support concurrent contract cases and independent optional tasks without serializing unrelated requests. |
| Availability / Resilience | Make deterministic operations idempotent by case reference and operation; retry transient integration failures without duplicating notices, packets, or filings. |
| Logging & Monitoring | Audit every decision, task owner, comment, status change, SLA warning, breach response, integration call, and final disposition. |
| Compliance | Preserve the full decision and document trail; require explicit human legal disposition before signature; prevent reopening after Executed, Rejected, or Withdrawn. |

## Testing Strategy

| Scenario | Setup | Expected Outcome |
|---|---|---|
| Happy path | Complete request; Counsel approves; Senior Counsel sends to signature; signature succeeds | Contract is delivered, filed, and closes as Executed. |
| Counsel rejection | Counsel chooses Reject with reason | Rejection notice and audit log complete; case closes as Rejected. |
| Senior Counsel rejection | Counsel approves; Senior Counsel chooses Reject | Rejection wrap-up completes and closes as Rejected. |
| Signature decline | Senior Counsel sends to signature; counterparty declines | Signature stage diverts to rejection wrap-up and closes as Rejected. |
| Signature expiry | Senior Counsel sends to signature; signature event reports expired | Signature stage diverts to rejection wrap-up and closes as Rejected. |
| Correction loop | Counsel returns for corrections; Requester fixes and resubmits; Counsel later approves | Checking tasks rerun with fresh results; the case proceeds to decision without stale routing state. |
| Withdrawal from each review phase | Trigger withdrawal during Checking, Counsel, and Senior counsel review | One interrupting lane cancels work, confirms withdrawal, and closes as Withdrawn. |
| Optional Counsel actions | Ask a question and order an outside opinion during Counsel review | Both remain phase-scoped; the opinion is available to later decision-makers. |
| Optional Finance sign-off | Senior Counsel triggers Finance Controller review | Finance opinion is captured before Senior Counsel completes the final decision. |
| Optional obligation tracking | Launch the child case during Signature and filing | A linked tracking case is created without blocking the contract case. |
| Phase at-risk | Advance each phase clock to 70% | The correct phase owner receives a warning; no routing change occurs. |
| Phase breach | Breach each phase SLA | Legal Operations Lead receives intervention work and the Requester receives a revised expected date; Counsel breach also bumps to Senior Counsel. |
| Overall SLA breach | Breach the 10-business-day SLA | Overall SLA Intervention interrupts, performs the breach response, requires General Counsel review, and returns to the prior stage. |
| Closed-case immutability | Attempt updates or transitions after each final outcome | Executed, Rejected, and Withdrawn cases cannot reopen or move. |
| Integration failure | Force API, portal, e-signature, and repository errors | Errors are logged, retries remain idempotent, and no duplicate external action is created. |
