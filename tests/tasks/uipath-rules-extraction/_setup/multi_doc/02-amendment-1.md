# Amendment 1 to the Travel Expense Reimbursement Policy, Version 2.0
Effective July 1, 2026. Issued by Finance.
## Changes
Section 3, first sentence, is replaced with: "Hotel cost is reimbursed up to $225 per night for domestic travel."
Section 4, first sentence, is replaced with: "Meals are reimbursed up to $65 per day for domestic travel and $90 per day for international travel."
All other sections are unchanged.
