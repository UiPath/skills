Usage: uip agenthub remote-a2a-agent-user-connections delete [options]

Remove a user's connection from a remote A2A agent.

The user's calls then use the agent's own connection. Your own needs
Connections.Edit in the agent's folder; another user's also needs
McpServers.Edit there.

Options:
  --me                        Remove your own connection.
  --user-id <id>              Remove this user's connection. `uip admin users
                              list` shows each user's id beside their email.
  --user-email <email>        Remove the connection of the organization's user
                              with this email. Looking it up needs permission to
                              read the organization's users.
  --dry-run                   Print the mutation plan without removing it.
  -y, --yes                   Confirm this irreversible operation (required; the
                              CLI never prompts)
  --agent <slug>              Remote A2A agent slug, not its display name.
  --folder-key <key>          Orchestrator folder key (GUID). Use --folder-path
                              for the folder name or fully-qualified path.
  --folder-path <path>        Orchestrator folder display name or
                              fully-qualified path (e.g. 'Shared' or
                              'Foo/Shared'). Resolved to the folder key via the
                              Orchestrator SDK.
  --login-validity <minutes>  Override the interactive-login token lifetime for
                              this call.
  -h, --help                  display help for command
