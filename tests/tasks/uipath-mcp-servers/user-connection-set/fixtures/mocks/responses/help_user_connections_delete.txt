                    uip agenthub mcp-user-connections delete                    
Remove a user's connection from a remote MCP server.

The user's calls then use the server's own connection. Your own needs
Connections.Edit in the server's folder; another user's also needs
McpServers.Edit there.
                Use --help with nested commands for more detail.                

┌─ Usage ──────────────────────────────────────────────────────────────────────┐
│ uip agenthub mcp-user-connections delete [options]                           │
└──────────────────────────────────────────────────────────────────────────────┘

┌─ Options ────────────────────────────────────────────────────────────────────┐
│ --mcp <slug>                   Parent MCP server slug, not its display name. │
│ --me                           Remove your own connection.                   │
│ --user-id <id>                 Remove this user's connection. `uip admin     │
│                                users list` shows each user's id beside their │
│                                email.                                        │
│ --user-email <email>           Remove the connection of the organization's   │
│                                user with this email. Looking it up needs     │
│                                permission to read the organization's users.  │
│ --dry-run                      Print the mutation plan without removing it.  │
│ -y, --yes                      Confirm this irreversible operation           │
│                                (required; the CLI never prompts)             │
│ --folder-key <key>             Orchestrator folder key (GUID). Use           │
│                                --folder-path for the folder name or          │
│                                fully-qualified path.                         │
│ --folder-path <path>           Orchestrator folder display name or           │
│                                fully-qualified path (e.g. 'Shared' or        │
│                                'Foo/Shared'). Resolved to the folder key via │
│                                the Orchestrator SDK.                         │
│ --login-validity <minutes>     Override the interactive-login token lifetime │
│                                for this call.                                │
│ -h, --help                     display help for command                      │
│ --output                       Output format (default: json)                 │
│ <table|json|yaml|plain|markd                                                 │
│ own>                                                                         │
│ --output-filter <expression>   JMESPath expression applied to the Data field │
│                                of the response envelope                      │
│ --log-level                    Log level threshold (default: info)           │
│ <debug|info|warn|error>                                                      │
│ --log-file <path>              Write logs to file instead of stderr          │
│ --profile <name>               Use a named login profile                     │
└──────────────────────────────────────────────────────────────────────────────┘

┌─ Examples ───────────────────────────────────────────────────────────────────┐
│ Remove your own connection, so your calls use the server's again             │
│                                                                              │
│   $ uip agenthub mcp-user-connections delete --mcp vendor-mcp --me --folder-path Shared --yes │
│                                                                              │
│   slug     vendor-mcp                                                        │
│   userId   3f6c1d2e-8a4b-4c7d-9e1f-0a2b3c4d5e6f                              │
│   cleared  true                                                              │
└──────────────────────────────────────────────────────────────────────────────┘
