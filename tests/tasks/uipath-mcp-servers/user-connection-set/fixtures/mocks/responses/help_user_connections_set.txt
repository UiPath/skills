                     uip agenthub mcp-user-connections set                      
Set a user's connection on a remote MCP server, replacing any they have.

The connection must be Enabled. Your own needs Connections.Edit in the
server's folder; another user's also needs McpServers.Edit there.
                Use --help with nested commands for more detail.                

┌─ Usage ──────────────────────────────────────────────────────────────────────┐
│ uip agenthub mcp-user-connections set [options]                              │
└──────────────────────────────────────────────────────────────────────────────┘

┌─ Options ────────────────────────────────────────────────────────────────────┐
│ --mcp <slug>                   Parent MCP server slug, not its display name. │
│ --connection-id <id>           Integration Service connection, by id, that   │
│                                the user's calls authenticate with: an OAuth  │
│                                connection of the UiPath MCP connector, from  │
│                                `uip is connections list uipath-uipath-mcp    │
│                                --all-folders`.                               │
│ --connection-name <name>       The connection by name instead of             │
│                                --connection-id: one of the UiPath MCP        │
│                                connector's connections you can see.          │
│ --me                           Set your own connection.                      │
│ --user-id <id>                 Set this user's connection. `uip admin users  │
│                                list` shows each user's id beside their       │
│                                email.                                        │
│ --user-email <email>           Set the connection of the organization's user │
│                                with this email. Looking it up needs          │
│                                permission to read the organization's users.  │
│ --user-name <name>             Name `list` shows for the user. Defaults to   │
│                                the --user-email; your own shows the email of │
│                                your login when it has one.                   │
│ --dry-run                      Print the mutation plan without setting it.   │
│ --folder-key <key>             Orchestrator folder key (GUID). Use           │
│                                --folder-path for the folder name or          │
│                                fully-qualified path.                         │
│ --folder-path <path>           Orchestrator folder display name or           │
│                                fully-qualified path (e.g. 'Shared' or        │
│                                'Foo/Shared'). Resolved to the folder key via │
│                                the Orchestrator SDK.                         │
│ --login-validity <minutes>     Override the interactive-login token lifetime │
│                                for this call.                                │
│ -h, --help                     display help for command                      │
│ --output                       Output format (default: json)                 │
│ <table|json|yaml|plain|markd                                                 │
│ own>                                                                         │
│ --output-filter <expression>   JMESPath expression applied to the Data field │
│                                of the response envelope                      │
│ --log-level                    Log level threshold (default: info)           │
│ <debug|info|warn|error>                                                      │
│ --log-file <path>              Write logs to file instead of stderr          │
│ --profile <name>               Use a named login profile                     │
└──────────────────────────────────────────────────────────────────────────────┘
