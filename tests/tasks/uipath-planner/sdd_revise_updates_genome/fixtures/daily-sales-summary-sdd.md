## 1. Process Overview

The sales offices drop one CSV export per region into a shared input folder during the day. Every weekday at 19:00 the automation totals the day's sales lines per region into one Excel summary named after the business date and archives the files it read. The run succeeds or fails as a whole.

## 2. Process Map

1. List the CSV exports in the input folder (19:00, weekdays).
2. Read every export into one table of sales lines.
3. Total the lines at or above the minimum amount per region and currency.
4. Write the summary workbook to the output folder.
5. Move every export read into the archive folder.

## 3. Detailed Process Steps

| Step | Action | Application | Expected result |
|---|---|---|---|
| 3.1 | List every file ending in `.csv` in the input folder; none: log "no exports arrived" and end | File system | List of exports |
| 3.2 | Read each export with its header row (Region, OrderId, Amount, Currency, OrderDate) | CSV files | One table of sales lines |
| 3.3 | Keep the lines at or above the minimum amount (BR-1); group by Region and Currency; count and total | — | One total per region and currency |
| 3.4 | Write `Sales Summary <yyyy-MM-dd>.xlsx` with Region, Currency, Lines, Total, sorted by Region, on sheet `Summary` | Excel file | Workbook in the output folder |
| 3.5 | Move every listed export into the archive folder, replacing a same-named file | File system | Input folder empty of CSV files |

## 4. Business Rules

| ID | Rule |
|---|---|
| BR-1 | A sales line whose Amount is below 10.00 is left out of the totals. |
| BR-2 | A line whose Amount is empty or not a number is left out of the totals and counted in the job log. |
| BR-3 | Only files ending in `.csv` are read; any other file stays in the input folder. |
| BR-4 | Exports are archived only after the summary workbook is written. |

## 7. Exception Handling

Not transactional: no business exceptions per item. A run either writes the summary and archives every export, or stops with nothing archived.

## 8. Error Handling

| ID | Error | Handling |
|---|---|---|
| SE-1 | An export lacks its Region or Amount column | Stop the run with a message naming the file; nothing written, nothing archived |
| SE-2 | The workbook cannot be written | Stop before archiving; every export stays in the input folder |
