## 1. Process Overview

The sales offices drop one CSV export per region into a shared input folder during the day. Every weekday at 19:00 the automation reads every export in that folder, keeps the sales lines at or above a minimum amount, totals them per region and currency, and writes a one-sheet Excel summary named after the business date into the output folder. It then moves every file it read into the archive folder so the next run starts from an empty input folder.

## 2. Process Map

1. List the CSV exports in the input folder (19:00, weekdays).
2. Read every export into one table of sales lines.
3. Total the lines at or above the minimum amount per region and currency.
4. Write the summary workbook to the output folder.
5. Move every export read into the archive folder.

## 3. Detailed Process Steps

| Step | Action | Application | Expected result |
|---|---|---|---|
| 3.1 | List every file ending in `.csv` in the input folder; none → log "no exports arrived" and end | File system | List of exports |
| 3.2 | Read each export with its header row (Region, OrderId, Amount, Currency, OrderDate) into one table | CSV files | One table of sales lines |
| 3.3 | Keep lines whose Amount is at least the minimum amount; group by Region and Currency; sum Amount and count lines | — | Totals per region and currency |
| 3.4 | Write `Sales Summary <yyyy-MM-dd>.xlsx` to the output folder, sheet "Summary", columns Region, Currency, Lines, Total, sorted by Region | Excel file | Summary workbook |
| 3.5 | Move every export listed in 3.1 to the archive folder, replacing a file of the same name | File system | Input folder empty of CSV files |

## 4. Business Rules

| ID | Rule |
|---|---|
| BR-1 | Only files ending in `.csv` are read; any other file stays in the input folder. |
| BR-2 | A line whose Amount is below the minimum amount (10.00 [SME REVIEW]) is left out of the totals. |
| BR-3 | A line whose Amount is empty or not a number is left out of the totals and counted in the job log. |
| BR-4 | The run is all or nothing: exports are archived only after the summary workbook is written. |

## 8. Error Handling

| ID | Error | Handling |
|---|---|---|
| SE-1 | An export lacks its Region or Amount column | Stop the run with a message naming the file; nothing written, nothing archived |
| SE-2 | The workbook cannot be written | Stop before archiving; every export stays in the input folder |
