## 1. Process Overview

The case `SupplierOnboarding` starts this process once per approved supplier request. It signs in to SAP GUI, creates the supplier as a vendor with transaction XK01, reads back the vendor number and returns it to the case.

## 3. Detailed Process Steps

| Step | Action | Application | Expected result |
|---|---|---|---|
| 3.1 | Sign in to SAP GUI with the robot account | SAP GUI | SAP Easy Access |
| 3.2 | Search the vendor master by tax identifier | SAP GUI | No vendor found, or the existing vendor number |
| 3.3 | Open transaction XK01 and enter name, country, tax identifier and bank account holder | SAP GUI | Vendor form filled |
| 3.4 | Save and read back the vendor number from the status bar | SAP GUI | Vendor number |
| 3.5 | Return the vendor number and the result (Created, Duplicate, Failed) to the case | — | Output arguments set |

## 4. Business Rules

| ID | Rule |
|---|---|
| BR-1 | A supplier whose tax identifier already exists in SAP is not created again: return the existing vendor number with result Duplicate. |

## 5. Data Definitions

| Argument | Direction | Type | Description |
|---|---|---|---|
| SupplierName | In | String | Legal name of the supplier |
| Country | In | String | ISO country code |
| TaxIdentifier | In | String | Tax identifier from the request |
| BankAccountHolder | In | String | Name on the supplier's bank account |
| VendorNumber | Out | String | SAP vendor number |
| Result | Out | String | Created, Duplicate or Failed |

## 8. Error Handling

| ID | Error | Handling |
|---|---|---|
| SE-1 | SAP GUI session lost or transaction times out | Close SAP GUI, sign in again and retry the vendor 2 times [DEFAULT]; then return result Failed with the reason |
