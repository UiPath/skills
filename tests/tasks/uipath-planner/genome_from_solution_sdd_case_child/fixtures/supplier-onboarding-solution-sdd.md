## Recommended Scope

**Delivery model:** cloud
**Blocked by platform:** none
**Need profile:** Every supplier request reaches a decision and, when approved, a SAP vendor number within 5 business days.

## 1. Solution Overview

Procurement receives about 40 supplier onboarding requests a week through a request form. Each request is reviewed by procurement, checked by compliance, and, when approved, the supplier is created as a vendor in SAP. Today the steps are tracked in a spreadsheet and requests stall between teams. The solution manages each request as a case and creates the vendor in SAP with a robot.
