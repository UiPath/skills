> **Studio Web:** remote sessions are not available here. The `uip rpa remote` commands and the `--remote` flag on `run` / `debug start` do not exist in this host, and the `uip rpa` CLI tool is otherwise limited to the host-served `uip rpa init` and `uip rpa run` (see SKILL.md § Studio Web Scope). Do not run any command in this file. When the user asks to design, debug, or run a workflow on a remote machine, tell them remote sessions are not supported in Studio Web and run through the `uip rpa` CLI outside this host.
