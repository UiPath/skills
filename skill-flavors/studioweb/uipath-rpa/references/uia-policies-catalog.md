4. **Hand the cleanup to the user.** Studio Web has no UI Automation CLI, so this host cannot list windows, reset an app, or close a window. After every run, whether it succeeded, failed, or was cancelled, tell the user which apps the workflow drove. Ask them to close any window the run opened. After a failed or cancelled run, also ask them to check each app and undo only what the run changed, using cancel, close without saving, or navigate back. They must not save, submit, or confirm anything. Windows and state that were already open before the run belong to the user and stay as they are.
