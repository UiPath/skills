4. **Hand the cleanup to the user.** Studio Web has no UI Automation CLI, so this host cannot list windows, reset an app, or close a window. After every run, whether it succeeded, failed, or was cancelled, tell the user which apps the workflow drove. After a failed or cancelled run, first ask them to undo only what the run changed in each app, using cancel, close without saving, or navigate back. They must not save, submit, or confirm anything. Do this before closing any window, because some apps restore unsaved state when reopened. After every run, ask them to close any window the run opened. Windows and state that were already open before the run belong to the user and stay as they are.
