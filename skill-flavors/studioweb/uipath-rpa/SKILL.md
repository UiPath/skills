**Studio Web destination → the project is already in Studio Web.** Build the RPA project inside the open solution (`uip rpa init <NAME>` from `/solution` creates it there); no solution wrapping, import, or upload step applies. Local execution (`uip rpa run`) and the Orchestrator package flow (`uip rpa pack` → `uip or packages upload` — there is no `uip rpa publish`) work on the project as-is.
