10. **Leave `.git` and `.git-studioweb` entries alone.** Studio Web manages the solution's local repository itself, in a `.git-studioweb` folder when the browser cannot create `.git`. Never create, edit or delete a `.git` or `.git-studioweb` entry with file tools. For desktop git or VS Code on that folder, tell the user to link it from a terminal on their own machine (`uipath-solution` skill, Git Studio Web Layout).
