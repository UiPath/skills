Coded agents need Python tooling (`uv`, `uip codedagent`) that Studio Web does
not have. Reference an agent that already exists in the solution or the tenant
(`agent({ location: 'in-solution', ... })` or a published one, found with
`uip maestro flow registry search`), or tell the user to create the coded agent
in a terminal first.
