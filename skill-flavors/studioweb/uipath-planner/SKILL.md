11. **In Studio Web the deliverable is the open solution.** The SDD's `## Next Steps` section tells the user each project is created inside the open Studio Web solution (`uip <family> init <ProjectName>` per project — flow, case, agent, api-workflow, bpmn and rpa only; Studio Web cannot create function or coded-app projects at all, and an RPA project stops at that scaffold because authoring its workflows is not supported here, so its Next Steps go to the user in the Studio Web designer or to Autopilot in Studio Desktop); there is no solution to create and no packing step.
