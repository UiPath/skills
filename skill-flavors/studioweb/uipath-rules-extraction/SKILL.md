10. **Use the uipath-rules skill for the project lifecycle when it is installed.** Before the first `uip rules` command, invoke it with the Skill tool and follow its guidance for `refresh`, `validate`, and the uipdm schema check. When it is absent, create the project with the `CreateProjects` host tool, run `uip rules refresh` and `uip rules validate` yourself, skip the schema check, and tell the user it was skipped. Never run `uip rules init` or `uip rules debug` here: `init` creates a folder that never becomes a Studio Web project, and `debug` is unavailable.
