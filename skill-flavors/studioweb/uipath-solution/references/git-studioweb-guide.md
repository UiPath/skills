> **In Studio Web, this page is for the user's own machine.** Studio Web creates and finds `.git-studioweb` itself; the browser cannot create a `.git` entry, and the CLI here cannot link it. Never create, edit or delete a `.git` or `.git-studioweb` entry with file tools. Hand the commands below to the user to run in a terminal on their machine. When a `.git` folder and `.git-studioweb` both exist, explain the split to the user (see [When a `.git` Folder and `.git-studioweb` Both Exist](#when-a-git-folder-and-git-studioweb-both-exist)) and leave the recovery commands to them.
