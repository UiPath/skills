`deploy run`, `deploy list`, `packages list` and `packages delete` take
`--feed <name-or-key>` or `--personal-workspace` to target a feed other than the
tenant's. `publish` in Studio Web never takes `--feed`: run it bare to list the
destinations, then pass `--location` or `--personal-workspace`. See
[Pack and Deploy — Choosing the publish destination in Studio Web](pack-and-deploy.md#choosing-the-publish-destination-in-studio-web).
