**IP Restriction is not available on Automation Suite.** Automation Suite does not ship the IP Restriction service, so every `uip admin ip-restriction` command fails there. Do not run them, and do not try another way to allowlist IPs or enforce restrictions. Tell the user that IP Restriction is an Automation Cloud feature, and stop. The rules below apply to Automation Cloud only.
