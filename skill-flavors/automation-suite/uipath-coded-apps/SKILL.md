## Automation Suite Scope

**Coded Apps are not available on Automation Suite.** Automation Suite does not host Coded Web Apps or Coded Action Apps, so `uip codedapp` cannot publish or deploy an app there, and an app built against a cloud tenant cannot be moved to an Automation Suite tenant.

Do not scaffold, build, publish or deploy a Coded App for an Automation Suite tenant, and do not substitute another product. Tell the user that Coded Apps are available on Automation Cloud only, and stop.
