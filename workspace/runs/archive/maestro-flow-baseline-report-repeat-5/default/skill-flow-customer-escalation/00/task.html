### What was built

```
Email Received (Outlook trigger)
  → Classify Urgency (script)
  → Classify VIP (script)
  → Decision: Urgent AND VIP?
     ├── true  → Notify Slack VIP → Reply High-Touch Ack → End High-Touch
     └── false → Generate Support Ticket (script) → Reply Standard Ticket → End Standard
```

**Trigger:** `uipath.connector.trigger.uipath-microsoft-outlook365.email-received` — polls the Inbox folder, configured with connection `is-sandboxes-test@uipathsandboxes.onmicrosoft.com` (folder: `uipath-maestro-flow`).

**Urgency classification** (`classifyUrgency` script): scans subject + body for keywords — `urgent`, `critical`, `asap`, `emergency`, `immediate`, `outage`, `down`, `blocker`, `sev1`, `severity 1`, `production down`, `incident`.

**VIP classification** (`classifyVip` script): domain allow-list (`enterprise.com`, `acme.com`, `bigclient.com`, `keyaccount.com`, `goldpartner.com`) + explicit VIP address list (`ceo@example.com`, `cto@example.com`, `vip@partner.org`).

**Decision** (`routeDecision`): `$vars.classifyUrgency.output.isUrgent && $vars.classifyVip.output.isVip`

**High-touch branch (urgent AND VIP):**
- Posts to `#escalations-vip` Slack channel with sender + subject
- Replies to sender via Outlook with a 1-hour-response SLA acknowledgment

**Standard branch:**
- Generates a ticket ID (deterministic hash: `TKT-NNNNN`) with a 24-hour SLA message
- Replies to sender via Outlook with the ticket details
