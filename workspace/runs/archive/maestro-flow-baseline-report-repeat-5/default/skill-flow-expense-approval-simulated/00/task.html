### What was built

Here's the full process your flow automates:

```mermaid
graph LR
    start(Manual Trigger)
    validateExpense[Validate Expense Report]
    checkValidation{Is Expense Valid}
    logInvalidExpense[Log Invalid Submission]
    managerApproval[Manager Approval]
    checkApproval{Approved by Manager}
    logApproved[Log Approved Expense]
    logRejected[Log Rejected Expense]
    doneApproved(Done Approved)
    doneRejected(Done Rejected)
    doneInvalid(Done Invalid)
    start -->|output| validateExpense
    validateExpense -->|success| checkValidation
    checkValidation -->|true| managerApproval
    checkValidation -->|false| logInvalidExpense
    logInvalidExpense -->|success| doneInvalid
    managerApproval -->|completed| checkApproval
    checkApproval -->|true| logApproved
    checkApproval -->|false| logRejected
    logApproved -->|success| doneApproved
    logRejected -->|success| doneRejected
```

**11 nodes across 3 outcome paths:**

| Node | Purpose |
|---|---|
| **Manual Trigger** | Employee or system submits an expense report with `employeeId`, `employeeName`, `amount`, `description`, `category`, `receiptUrl` |
| **Validate Expense Report** | Checks required fields are present, auto-generates a unique `expenseId` (e.g. `EXP-E123-1234567890`) |
| **Is Expense Valid?** | Routes valid reports forward; sends invalid ones to a rejection log |
| **Log Invalid Submission** | Records validation failure with reason — your audit trail for bad submissions |
| **Manager Approval** | Pauses the flow and sends a task to the manager (via Email + Action Center) showing the full expense details; manager can Approve or Reject and add comments |
| **Approved by Manager?** | Branches on the manager's decision |
| **Log Approved Expense** | Records approval with timestamp, manager comments, and "payment processing initiated" message |
| **Log Rejected Expense** | Records rejection with timestamp, manager comments, and "employee will be notified" message |
| **3 × End nodes** | One per outcome (approved / rejected / invalid) |
