# SlackDigestBoundaryBpmn — CLI-Owned Enrichment Blockers

This project is a **local draft only**.  
Do NOT upload, publish, deploy, debug, or run until every blocker below is resolved.

---

## Why this file exists

`Task_SendSlack` (`bpmn:SendTask`, `Intsvc.ActivityExecution`) is an
**Integration Service connector node**.  
Its connector-specific fields — connection ID, connector key, folder key, object
name, operation method, URL path, request/response body schema, output bindings,
and all generated package metadata — are **CLI-owned enrichment**.  
They cannot be authored by hand without inventing identifiers, which is
prohibited.

---

## Blocker 1 — Connection ID (required before enrichment)

The binding placeholder `DRAFT_CONNECTION_ID` in `<uipath:bindings>` must be
replaced with the real `ConnectionId` from:

```
uip is connections list --all-folders --output json
```

Find the Slack connection row.  Record its `Id` field.

Do **not** invent or guess a connection GUID.

---

## Blocker 2 — Connector key, object name, operation metadata

The `DRAFT_CONNECTOR_KEY`, `DRAFT_ACTIVITY_NAME`, `DRAFT_METHOD`, and
`DRAFT_PATH` placeholders in `Task_SendSlack` must be replaced with values
generated by:

```
uip maestro bpmn registry get Intsvc.ActivityExecution \
    --connection-id <real-connection-id> \
    --object-name <real-object-name> \
    --output json
```

This command contacts the Integration Service catalog, resolves the live
connector schema for the chosen connection, and returns an `ISEnrichment` block
containing the correct `connectorKey`, `activity`, `method`, `path`, and the
exact `body` CDATA for the request shape.

Replace the entire `<uipath:context>` and `<uipath:input name="body">` blocks
in `Task_SendSlack` with what the CLI returns.  Do **not** hand-author these
from documentation or guesswork.

---

## Blocker 3 — Folder key

`DRAFT_FOLDER_KEY` must be replaced with the real Orchestrator folder key.
Resolve it from:

```
uip or folders list --output json
```

---

## Blocker 4 — Dynamic output schema

The `<uipath:output>` element for `Task_SendSlack` currently uses
`source="." type="custom"` as a structural placeholder.  
The real source path and type are generated by CLI enrichment (`ISEnrichment`
in the `registry get` response).  Replace them before packaging.

---

## Blocker 5 — `bindings_v2.json` resources array

`scripts/scaffold_metadata.py` generates a `bindings_v2.json` with an **empty
`resources` array** for projects that contain `Intsvc.*` nodes.  
The CLI pack step (`uip maestro bpmn pack`) must populate the `resources` array
with the live connection binding before the package is valid for upload.

Do **not** hand-edit `bindings_v2.json` with an invented connection resource
entry.

---

## Blocker 6 — All other package metadata files

After resolving blockers 1–4, regenerate the full metadata set:

```
python3 scripts/scaffold_metadata.py \
    --bpmn SlackDigestBoundaryBpmn/SlackDigestBoundaryBpmn.bpmn \
    --out-dir SlackDigestBoundaryBpmn/
```

This produces `project.uiproj`, `operate.json`, `entry-points.json`,
`bindings_v2.json` (with empty resources — see Blocker 5), and
`package-descriptor.json`.

Verify metadata drift before every pack:

```
python3 scripts/check_metadata_drift.py \
    --bpmn SlackDigestBoundaryBpmn/SlackDigestBoundaryBpmn.bpmn \
    --project-dir SlackDigestBoundaryBpmn/
```
