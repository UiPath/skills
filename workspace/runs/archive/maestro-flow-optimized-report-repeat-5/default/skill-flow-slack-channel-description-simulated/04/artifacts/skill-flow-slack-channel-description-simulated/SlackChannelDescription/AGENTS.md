## Key Design Notes

- **Token storage**: `GetRobotAsset` activity retrieves an Orchestrator asset named `SlackBotToken` (String type, must exist before running)
- **API endpoint**: `https://slack.com/api/conversations.list` — returns all channels the bot can see
- **Channel name in code**: `"office-bellevue"` (Slack API strips the `#` prefix)
- **Description field**: `purpose.value` inside each channel object
- **MessageBox**: Windows-only activity — runs correctly on attended Windows robots

## Required Setup

1. Create an Orchestrator Asset named `SlackBotToken` of type Text containing your Slack Bot Token (`xoxb-...`)
2. Ensure the bot has `channels:read` and `groups:read` scopes
3. Ensure the bot has been invited to `#office-bellevue` (or it's a public channel the bot can list)
