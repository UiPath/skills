## How to wire them together

To pipe the HTTP response into the Script node, reference the HTTP node's output inside the script body using the `$vars.` prefix:

```javascript
// Inside core.action.script → inputs.script
const response = $vars.httpRequest1.output;
const parsed = JSON.parse(response.body);
return {
  status: response.statusCode,
  result: parsed.someField
};
```

The critical rule: **always `$vars.<nodeId>.output`**, never the bare `<nodeId>.output` — the bare form resolves to `undefined` at runtime.
