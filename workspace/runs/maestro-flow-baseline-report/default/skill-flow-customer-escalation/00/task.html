### What was built

**10 nodes, 9 edges** across a branching topology:

```
Email Received (Outlook365 trigger)
  └─► Classify Urgency [Script]
        └─► Classify VIP [Script]
              └─► Urgent AND VIP? [Decision]
                    ├─ true (High Touch) ──► Slack Notify VIP [Slack connector]
                    │                             └─► Reply VIP Acknowledgment [Outlook Reply connector]
                    │                                       └─► End High Touch
                    └─ false (Standard) ──► Generate Support Ticket [Script]
                                                  └─► Reply Ticket Details [Outlook Reply connector]
                                                            └─► End Standard
```

---

### Classification logic

**Urgency keywords** (`classifyUrgency1` script):
- Scans subject + body for: `urgent`, `asap`, `critical`, `priority`, `emergency`, `outage`, `down`, `broken`, `failure`, `escalate`, `immediately`, `time-sensitive`, `sev1`, `severity`

**VIP rule** (`classifyVip1` script — three signals, any one is sufficient):
1. **Domain allow-list:** `vip.com`, `enterprise.com`, `gold-tier.com`, `premium.com`, `platinum.com`, `strategic-partner.com`
2. **Email allow-list:** `ceo@example.com`, `cto@example.com`, `vp@example.com`, `president@example.com`
3. **Subject tag:** `[vip]`, `[vip customer]`, or `[premium]` in subject
