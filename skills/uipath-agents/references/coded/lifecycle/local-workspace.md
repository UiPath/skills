# Studio Web Local Workspace — State Reference

Consult when quickstart's Project State Detection sets `project_state = local-workspace`. The lifecycle is in [../quickstart.md](../quickstart.md); this file covers detection, ownership, and recovery.

## Detection

An ancestor of the agent project directory contains either `.sw-path-marker` or `.local/folder.lock`; Studio Web drops these when it actively manages the folder. A `*.uipx` solution manifest does not qualify by itself because every UiPath solution has one, including CLI-only and git-cloned solutions never opened in Studio Web.

Inside the agent project, `.uipath/local-project-id.json`, `.uipath/studio_metadata.json`, and `.env` with `UIPATH_PROJECT_ID=<guid>` confirm Local Workspace but do not prove it; cloud-workspace projects pulled via `uipath pull` can also contain them.

## Layout

```
<workspace-root>/
└── <SolutionName>/
    ├── .sw-path-marker
    ├── .local/folder.lock
    ├── <SolutionName>.uipx
    ├── resources/
    └── <AgentDir>/
        ├── pyproject.toml
        ├── main.py
        ├── <framework>.json
        ├── entry-points.json
        ├── bindings.json
        ├── uipath.json
        ├── project.uiproj
        ├── .env
        └── .uipath/local-project-id.json
```

Change to `<AgentDir>` before running `uip codedagent` commands.

## Auto-Sync

`.local/folder.lock` means Studio Web watches the directory and propagates local saves to the remote SW project; SW edits flow back to the filesystem. Do not run `uip codedagent push` during normal iteration. Run `push --overwrite` or `pull --overwrite` only to recover when sync is paused, the workspace was opened detached, the lock expired, or a remote conflict occurred.

## Files Owned by Studio Web — Do Not Edit

- `project.uiproj`
- `.uipath/local-project-id.json`
- `.uipath/studio_metadata.json`
- `.local/folder.lock` in the solution root
- `<SolutionName>.uipx` and `.sw-path-marker` in the solution root

You own `main.py`, `<framework>.json` coded fields, `pyproject.toml`, `bindings.json`, `evaluations/`, `entry-points.json` regenerated by `init`, and `uipath.json` `packOptions` and `runtimeOptions`.

## Schema Sync After Edits

`entry-points.json` is generated from `main.py`; auto-sync does not regenerate it. After any `main.py` edit that changes `Input`/`Output`/`State` Pydantic models, TypedDicts, or the entry function signature—including adding, removing, renaming, or retyping a field—run `uip codedagent init` before `uip codedagent run`. Otherwise schemas remain stale and new fields are invisible to the runtime and downstream consumers.

Skip `init` only for edits inside node bodies or helpers that leave every Pydantic/TypedDict shape and the entry-function signature byte-identical.

## Anti-Patterns

- Do not run `uip codedagent new`; it overwrites Studio Web scaffolding and orphans the SW project ID.
- Do not run `uip codedagent push` during iteration; auto-sync covers it. Use manual `push` only for recovery.
- Do not delete `project.uiproj`; Studio Web requires it. Auto-sync or `pull` as fallback will restore it.
- Do not change `UIPATH_PROJECT_ID` in `.env`; it identifies the synced Studio Web project. Changing it sends a fallback `push` to the wrong project and breaks auto-sync identity.
- Do not skip `uip codedagent init` after schema or entry-signature edits in `main.py`; run it before `run`.

## Troubleshooting

| Error | Cause | Fix |
|---|---|---|
| `uipath executable not found` on `run` / `eval` | `.venv` was not created or `setup --force` was not run after creating it | Run quickstart step 2's `local-workspace` venv prep block |
| Local edit is not visible in Studio Web after a few seconds | Auto-sync is paused due to a detached workspace, expired lock, or network glitch | Re-open the workspace in Studio Web; if still missing, run `uip codedagent push --overwrite` once to reconcile |
| `Your local version is behind the remote version. Aborted!` on fallback `push` | SW or another local session edited the project while auto-sync was paused | Run `uip codedagent pull --overwrite`, reconcile, then run `push --overwrite` |
| `UIPATH_PROJECT_ID environment variable not found` on fallback `push` | `.env` is missing or `UIPATH_PROJECT_ID` was removed | Restore it from `.uipath/local-project-id.json`'s `projectId`; auto-sync will reconstitute `.env` after the next save |
| `401 Unauthorized` on fallback `push` or `eval --report` | Session expired | Re-authenticate per [../../authentication.md](../../authentication.md) |
